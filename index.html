About SentimentAI

A compact demo that shows how text → API → model → result flow works. Perfect for academic demos and quick prototypes.

Purpose

Teach and demonstrate sentiment analysis fundamentals: how to send text to a model and visualize the output.

Free-friendly

Designed to run on free tiers like GitHub Pages (frontend) and Render (backend) — no paid services required to demo.

Workflow

  1. Input: User types/pastes text in the frontend.
  2. Request: Frontend sends POST /analyze to backend.
  3. Model: Backend runs sentiment model (VADER or other) and returns label.
  4. Display: Frontend shows result and stores stats for dashboards.
